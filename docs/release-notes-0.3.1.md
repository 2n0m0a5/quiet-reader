# Quiet 0.3.1

Install **Quiet-0.3.1.apk** over any earlier version. Your library stays.

## Book folders
- Put your books in one folder on your phone, for example a "Books" folder in Downloads. Folders inside it are fine.
- In Quiet, tap **Add books → Add a book folder** and choose that folder. Quiet adds every book in it.
- **The app checks your book folders each time it opens**, so new books you put there show up by themselves. You can add several folders, and see and manage them in **Settings → Book folders**.
- Other kinds of files are ignored. Books you remove from Quiet aren't added back from the folder, and removing a book never deletes its file.
- On the website, choosing a folder adds its books once.

## Quotes have owners
- Saving a quote asks **who says it**: a character's name, or leave it empty for the narrator, and the quote is credited to the book's author. Names you've used in a book are suggested.
- Quotes show their owner everywhere, and you can change it later.
- Copied quotes are signed: *"…" — Elizabeth Bennet, in Pride and Prejudice by Jane Austen*.

## Translate
- When Google Translate is busy and turns a request away, Quiet asks **MyMemory**, a second free translation service. The window says which one translated, and only the selected text is sent.
